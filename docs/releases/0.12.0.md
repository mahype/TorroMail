# TorroMail 0.12.0

The macOS app can now configure individual Hermes bots with one click,
including bots running on a Mac connected through Hermes Desktop.

## New

- **Per-bot Hermes setup:** TorroMail discovers the standard bot and named
  profiles. Select the bots to configure and share all or selected mail
  accounts with each one. Every bot gets its own access key; new bots start
  with no shared accounts. Existing account selections migrate without
  widening access. Repeated setup keeps working keys stable.
- **Remote macOS setup:** TorroMail reads Hermes Desktop's saved connections
  and configures bots through an existing SSH connection. A remote URL backend
  is matched to a saved SSH host only when the match is unambiguous. Account
  choices and keys belong to TorroMail on the selected computer. Both Macs
  need TorroMail 0.12.0, and the remote user must have a signed-in macOS session.
- **Individual access checks and disconnect:** test a bot's configured key
  with an authenticated account-list call or revoke that bot independently.
  A failed setup restores its previous configuration, grants and key.

## Fixed

- Hermes setup repairs stale access keys and disabled or outdated TorroMail
  server entries while preserving other MCP servers, custom tool filters,
  extra environment variables and ordinary YAML comments.
- A successful setup check no longer clears a pending reload notice. The
  notice stays until the actual client connects with its configured key.
  If an existing Hermes session still lacks access, run `/reload-mcp` or start
  a new session.
- Native policy publication and Hermes bot setup coordinate their writes so
  newly paired bots remain in the access allowlist.

## Downloads and updates

The release includes the signed and notarized universal macOS app and terminal
programs, Linux terminal programs for x86_64 and aarch64 with the AUR package,
and experimental Windows x86_64 terminal programs. The per-bot setup interface
is available in the macOS app under **MCP Clients → Hermes**.

Installed release builds can update through Sparkle or the bundled terminal
updater. Development bundles keep automatic updates disabled; replace them
with the release DMG to return to normal updates.
