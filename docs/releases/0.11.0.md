# TorroMail 0.11.0

TorroMail can now connect Hermes automatically, and the macOS app includes a
terminal command for updating it when its window cannot open.

## New

- **Automatic Hermes setup** in the macOS app and terminal control surface:
  connect, reconnect, and disconnect with Hermes' own access key and account
  grants. Setup honors `HERMES_HOME` and the active Hermes profile, preserves
  other settings and MCP servers, and refuses to overwrite invalid YAML.
  After connecting, run `/reload-mcp` in Hermes or start a new session.
- **Google Antigravity pairing** with its own access key and shared-account
  selection. TorroMail detects the Antigravity profile or `agy` CLI and updates
  its global MCP configuration without changing the legacy Gemini CLI pairing.
- **Bundled macOS terminal control surface and updater**: dragging the app into
  Applications also installs `torromail` inside the bundle. To update the app
  when its window will not open, run:

  ```sh
  /Applications/TorroMail.app/Contents/MacOS/torromail update
  ```

  `update --check` checks without installing. The updater verifies Sparkle's
  signature and can replace and relaunch the app without an open window.

## Fixed

- Mail text with multibyte Unicode characters no longer risks a panic during
  HTML entity decoding.

## Downloads and updates

The release includes the signed and notarized universal macOS app and terminal
programs, Linux terminal programs for x86_64 and aarch64 with the AUR package,
and experimental Windows x86_64 terminal programs.

Installed macOS apps can use the normal Sparkle update. Apps at 0.10.5 or earlier
need one update through the app or DMG before the new terminal updater is
available. Development bundles keep automatic updates disabled.
